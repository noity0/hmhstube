This repository is ready for GitHub Pages deployment. Follow the steps below to enable your live site.

How to Enable GitHub Pages

Step 1: Fork the Repository

Go to https://github.com/noity0/hmhstube and click the "Fork" button.

Step 2: Enable GitHub Pages

Go to your forked repository settings, scroll to "GitHub Pages", select "Deploy from a branch", choose "main", and click "Save".

Step 3: Wait for Deployment

GitHub Pages will take a few minutes to deploy. Your site will be available at: https://YOUR_USERNAME.github.io/hmhstube/

Step 4: Update README

In the README, replace YOUR_USERNAME with your actual GitHub username.
